Protocol Standard & RFC Compliance

Guía de Códigos HTTP Semánticos

ChefAPI implementa respuestas HTTP. Cada error contiene un sobre de información estandarizado.

200 OK RFC 9110

Petición Exitosa

Se completó la lectura (GET) o una actualización idempotente (PUT), devolviendo el recurso solicitado en formato JSON.

201 Created RFC 9110

Recurso Materializado

Una receta o categoría fue creada correctamente y el servidor devuelve el URI del recurso generado mediante la cabecera Location.

400 Bad Request RFC 9110

Petición Deforme

El payload contiene errores de sintaxis, parámetros incompatibles o un encabezado Content-Type incorrecto.

404 Not Found RFC 9110

Recurso Inexistente

El identificador solicitado no existe dentro de las tablas maestras de PostgreSQL o SQLite.

409 Conflict Integridad Relacional

Colisión de Clave Foránea

Ocurre cuando se intenta eliminar una categoría con recetas asociadas o se duplica un slug declarado como único.

422 Unprocessable Pydantic Core

Fallo de Validación

El JSON es válido, pero incumple las reglas del modelo: valores negativos, cadenas vacías o enums inválidos.
